The Internet and the World Wide Web

Understand the differences between the Internet and the WWW, how webpages are accessed, how DNS works, and the main features and generations of the World Wide Web.

Section 1

Understanding the Internet and WWW

1.1 What is the Internet?

The Internet is a worldwide system of interconnected computer networks that communicate with one another using standard communication protocols.

Key Definition

The Internet is a global network of interconnected networks that allows computers and other devices to exchange data across the world.

Infrastructure of the Internet

The Internet depends on different types of hardware and communication technology.

🔀

Routers

Forward data packets between networks to help them reach their destinations.

🔌

Network Cables

Copper and fibre-optic cables provide physical connections for transmitting data.

📡

Wireless Networks

Wi-Fi, cellular networks and satellite links enable communication without direct cables.

🖥️

Servers

Provide resources and services such as websites, email and online applications.

1.2 What is the World Wide Web?

The World Wide Web is a system of interconnected webpages and resources that can be accessed over the Internet, normally using a web browser.

Key Definition

The World Wide Web (WWW) is a collection of interlinked webpages and other resources accessed using web technologies over the Internet.

Webpages can contain text, images, video, audio, hyperlinks and interactive features.

1.3 Internet vs World Wide Web

Internet World Wide Web
A global system of interconnected networks. A system of interconnected web resources.
Includes network infrastructure and protocols. Uses web technologies such as HTTP and HTML.
Supports email, file transfer, web browsing and other services. Provides webpages, websites and web applications.
Can be used without opening a web browser. Usually accessed through a web browser.
💡 Real-Life Example

Using Tr.Sun Education

When students open an educational website, the Internet carries data between their devices and the website's servers.

The website and its lesson pages form part of the World Wide Web.

✓ Internet = communication network
✓ WWW = connected web resources
Remember: The World Wide Web uses the Internet. However, the Internet provides many services besides the WWW.
💻
Section 2

Webpages, Websites, Browsers and Servers

2.1 Webpage

A webpage is a web document or resource that can be requested and displayed by a web browser.

Key Definition

A webpage is an individual document or resource displayed by a browser, commonly created using HTML.

Technologies Used to Create Webpages

🏗️

HTML

Defines the structure and content of a webpage, including headings, paragraphs, lists and links.

🎨

CSS

Controls the appearance of webpage elements, including colours, fonts, spacing and layout.

⚡

JavaScript

Adds interactive features and allows content to change in response to user actions.

2.2 Website

A website is a collection of related webpages and resources usually associated with the same domain name.

An educational website might contain:

  • A homepage.
  • Lesson pages.
  • Student registration pages.
  • Quizzes and assignments.
  • Teacher and student dashboards.

2.3 Web Browser

A web browser is software that allows users to request, retrieve and display web resources.

Examples include:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Apple Safari

Main Functions of a Browser

  1. Accept a URL from the user.
  2. Resolve domain names when required.
  3. Send requests to web servers.
  4. Receive webpage resources.
  5. Interpret HTML and CSS.
  6. Execute JavaScript.
  7. Display the webpage to the user.

2.4 Web Server

A web server is a computer system or software that responds to requests for web resources.

Key Definition

A web server receives requests from clients and sends back HTTP responses containing requested resources or information about the request.

A web server may provide:

  • HTML files
  • CSS files
  • JavaScript files
  • Images and videos
  • Dynamically generated content
💡 Example

Opening an Online Lesson

When a student requests a lesson page, the web server sends the resources required to display that lesson.

🔗
Section 3

IP Addresses, Domain Names and URLs

3.1 IP Address

Computers communicate over IP networks using numerical addresses.

Key Definition

An IP address is a numerical address used to identify a network interface and deliver data to the correct destination on an IP network.

Types of IP Addresses

Type Example Description
IPv4 192.0.2.10 Uses 32-bit addresses, commonly displayed as four decimal numbers.
IPv6 2001:db8::10 Uses 128-bit addresses, providing a much larger address space.

3.2 Domain Name

A domain name is a human-readable name used to identify a domain on the Internet.

Examples:

  • google.com
  • bbc.com
  • pearson.com

Domain names are easier for people to remember than numerical IP addresses.

3.3 Uniform Resource Locator (URL)

Key Definition

A URL is an address that identifies the location of a resource and the method used to access it.

Example URL:

https://www.example.com/lessons/topic3.html

Parts of a URL

🔒

Protocol / Scheme

https:// specifies secure HTTP communication.

🌐

Subdomain

www is a commonly used subdomain.

🏷️

Domain Name

example.com identifies the Internet domain.

📄

Resource Path

/lessons/topic3.html identifies a resource path.

HTTP and HTTPS

HTTP stands for Hypertext Transfer Protocol. It defines how web clients and web servers exchange requests and responses.

HTTPS is HTTP used over a secure, encrypted connection. It helps protect transmitted information from interception and alteration.

Important: HTTPS protects data in transit, but it does not automatically mean a website is trustworthy.
📒
Section 4

Domain Name System (DNS)

4.1 What is DNS?

People prefer to use domain names instead of remembering numerical IP addresses.

However, devices need appropriate network addresses to communicate with web servers.

Key Definition

The Domain Name System (DNS) is a distributed naming system used to find information, such as IP addresses, associated with domain names.

4.2 Why is DNS Necessary?

🧠

Easy to Remember

Users can remember domain names instead of numerical addresses.

🔄

Flexibility

A website can change server addresses without changing its domain name.

🌍

Scalability

Many DNS servers cooperate to manage large numbers of domain names.

⚡

Efficiency

DNS caching can reduce repeated lookups and improve performance.

4.3 How DNS Resolution Works

DNS resolution is the process of obtaining information such as an IP address for a domain name.

1
Enter the URL

The user enters a URL into the browser. The browser identifies the domain name.

↓
2
Check Available DNS Information

The device checks for a previously obtained result. If necessary, it asks a recursive DNS resolver.

↓
3
Search the DNS Hierarchy

If no cached answer is available, the resolver may contact root, TLD and authoritative DNS servers.

↓
4
Return the IP Address

The resolver returns the DNS result to the user's device.

↓
5
Contact the Web Server

The browser uses the obtained address to communicate with the web server.

4.4 The DNS Hierarchy

DNS Component Function
Recursive Resolver Searches for DNS information on behalf of the client and uses cached results when available.
Root DNS Server Provides referrals to the appropriate top-level domain servers.
Top-Level Domain Server Provides information about authoritative servers for domains under a TLD such as .com.
Authoritative DNS Server Provides DNS records for domains it is responsible for.
💡 DNS Example

Looking Up www.example.com

If the resolver has no cached answer, it can obtain referrals from root and .com DNS servers before requesting the relevant record from an authoritative DNS server.

The resolved address is then returned to the client.

4.5 When DNS Cannot Find a Domain

If a requested domain does not exist, DNS may return an error such as NXDOMAIN (non-existent domain).

Important Difference: A DNS name-resolution error is not the same as HTTP 404. A 404 error usually means the browser reached a web server but the requested resource was not found.
🔄
Section 5

How a Webpage is Requested and Delivered

When a user opens a website, the browser and web server exchange requests and responses using web communication protocols.

5.1 Step-by-Step Process

  1. Enter a URL: The user enters an address into the browser or clicks a hyperlink.
  2. Resolve the domain name: DNS is used if an appropriate address is not already available.
  3. Establish a connection: The browser establishes communication with the server. HTTPS also provides a secure encrypted connection.
  4. Send an HTTP request: The browser requests the required resource, often using the GET method.
  5. Process the request: The web server locates or generates the requested content.
  6. Send an HTTP response: The server responds with a status code and, when appropriate, the requested data.
  7. Retrieve additional resources: The browser may request CSS files, JavaScript files, images and other content.
  8. Display the webpage: The browser interprets the files and renders the webpage for the user.

5.2 Webpage Request Diagram

5.3 Common HTTP Status Codes

Code Meaning
200 OK The request was successful.
301 Moved Permanently The resource has been permanently redirected.
403 Forbidden The server refuses access to the resource.
404 Not Found The requested resource was not found.
500 Internal Server Error The server encountered an unexpected error.
Remember: DNS resolution identifies the server address. The HTTP request then asks the server for a resource. These are different stages.

Section 6

Main Features of the World Wide Web

The World Wide Web has several important characteristics that make it useful for communication, education, business and information sharing.

🔗

6.1 Hypertext Information System

Hypertext allows information to be connected through clickable hyperlinks. Links can connect webpages, documents, videos or other resources.

Benefits

  • Easy navigation.
  • Quick access to related information.
  • Supports non-linear learning.

Example: Students click a link to open another lesson.

📱

6.2 Cross-Platform

The WWW can be accessed using different types of devices and operating systems that support suitable web browsers.

Examples

  • Desktop computers
  • Laptops
  • Smartphones and tablets
  • Smart TVs and games consoles

Benefit: Students can access learning materials from different devices.

🌍

6.3 Distributed

Web resources are stored and delivered by many different servers around the world instead of one central computer.

Benefits

  • Distributes network traffic.
  • Supports large numbers of users.
  • Can improve reliability.
  • Can reduce loading times.

Example: A Content Delivery Network uses multiple locations to deliver website resources.

📏

6.4 Open Standards

Open standards are publicly available technical specifications that help different systems communicate and work together.

Examples

  • HTML
  • CSS
  • HTTP
  • URL standards

Benefit: Websites can work across browsers and devices implementing shared standards.

🔄

6.5 Dynamic

The WWW changes continuously as webpages are added, edited and updated. Individual webpages can also update content in response to user interactions.

Examples

  • Updated news articles
  • Current weather information
  • Social media feeds
  • Online shopping stock information

Benefit: Users can receive updated and personalised information.

🤝

6.6 Web 2.0

Web 2.0 describes a more participatory and interactive web in which users can create, share and discuss content.

Examples

  • Social media posts
  • Blog comments
  • Collaborative documents
  • Online discussion forums

Benefit: Encourages communication, collaboration and user participation.

Organisations Supporting Web Standards

The World Wide Web Consortium (W3C) develops important web standards. The Internet Engineering Task Force (IETF) develops many Internet and web-related protocol specifications.

The Internet Society supports an open and interoperable Internet.

Important: A distributed web does not mean that every website has decentralised ownership. Similarly, a dynamic WWW can still contain individual static webpages.
🤝
Section 7

Web 1.0 and Web 2.0

The development of the World Wide Web is commonly described using different generations.

7.1 Web 1.0 - The Read-Only Web

Web 1.0 describes the early web, where most information was published by website owners and visitors mainly read the content.

📄

Mostly Static Content

Many webpages displayed information that changed relatively infrequently.

👀

Limited Participation

Ordinary users had fewer opportunities to contribute or interact with content.

💡 Web 1.0 Example

Early School Website

A school website displays its address, telephone number, timetable and basic information. Students mainly read this information.

7.2 Web 2.0 - The Read-Write Web

Web 2.0 describes the growth of interactive websites that support user-generated content, collaboration and social interaction.

✍️

User-Generated Content

Users can create posts, comments, reviews, photographs and videos.

💬

Collaboration

Users can communicate, work together and share information online.

👤

Personalisation

Websites may provide accounts, customised content and user preferences.

⚡

Interactive Services

Users can submit forms, upload files, post messages and receive updates.

7.3 Web 1.0 vs Web 2.0

Feature Web 1.0 Web 2.0
Main Focus Publishing information Participation and collaboration
User Role Mainly reader Reader and contributor
Content Creation Mainly website owners Website owners and users
Interactivity Often limited Often high
Webpage Types Often static Often dynamic
Communication Mainly one-way Often two-way or many-to-many
Examples Early information websites Blogs, wikis and social platforms

7.4 Benefits and Challenges of Web 2.0

✅

Benefits

  • Greater collaboration.
  • Easier content sharing.
  • Online communities.
  • More user participation.
⚠️

Challenges

  • Misinformation.
  • Privacy risks.
  • Cyberbullying.
  • Inappropriate content.
Remember: Web 1.0 and Web 2.0 are broad descriptions of how the web evolved. They are not completely separate technical systems.
🧠
Section 8

Understanding Web 3.0

Web 3.0 is a term used to describe several ideas about the development of the World Wide Web.

Two important interpretations are the Semantic Web and the decentralised Web3.

8.1 Web 3.0 and the Semantic Web

The Semantic Web is a vision of the web in which online information is described using structured, machine-readable data.

Key Definition

The Semantic Web aims to organise online data so that computer systems can interpret, connect and process information more effectively.

Potential Benefits

🔍

Better Information Discovery

Structured data can help systems identify related information.

🤖

Automated Processing

Software can process and combine machine-readable information.

🔗

Linked Data

Information from different sources can be connected using shared meanings.

⚙️

Interoperability

Different systems can exchange and interpret structured data more easily.

8.2 Web3 and Decentralisation

Another use of the term Web3 refers to decentralised applications and technologies, often involving blockchains.

The aim is to explore systems where users may have greater control over certain digital assets or identities, without depending exclusively on traditional central platforms.

Common Concepts

  • Blockchain: A distributed ledger technology.
  • Decentralised Applications: Applications that use decentralised infrastructure for some functions.
  • Digital Wallets: Tools for managing digital assets and associated credentials.
  • Smart Contracts: Programs that execute defined operations on compatible blockchain systems.

8.3 Effects on Different Groups

Group Possible Impact
Users More sophisticated online services, improved data connections and potentially greater control over digital identities.
Software Developers New approaches involving structured data, linked data, decentralised applications and related technologies.
Web Designers New interface design challenges involving accessibility, usability and the presentation of complex information.
Organisations New possibilities for data interoperability, automation and digital service models.

8.4 Comparison of Web Generations

Aspect Web 1.0 Web 2.0 Web 3.0 / Web3
Description Read Read and write Machine-readable data and/or user control
Focus Publishing Participation Data interoperability and/or decentralisation
Typical Technologies Early HTML websites Interactive web applications Semantic Web technologies and/or blockchain
Development Historical phase Widely established Evolving concepts
Important: The Semantic Web and blockchain-based Web3 are different concepts. The term Web 3.0 does not have one universally accepted technical meaning.

DNS A distributed system for looking up information associated with domain names.
HTTP A protocol for exchanging web requests and responses.
HTTPS HTTP communication protected by a secure encrypted connection.
Hyperlink A reference that users can follow to another resource.
Hypertext Text containing links to related information or resources.
Cross-Platform Able to operate across different devices or software platforms.
