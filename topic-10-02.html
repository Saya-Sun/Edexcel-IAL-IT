Web Typography

Understand web-safe fonts, font fallback lists and embedded web fonts — and discover how typography shapes readable, reliable websites.

Topic 10.2Syllabus 10.1.29 lesson sections

In this lesson: Learn how web-safe fonts work, how to use font-family in CSS, how embedded fonts are delivered, and when each approach is appropriate. All examples are included in these notes.

SECTION 01

Introduction to Web Typography

Web typography refers to the selection, arrangement and formatting of text on a website to make it readable, visually appealing and consistent.

Typography is an important part of web design because most websites communicate information through text.

When designing a website, a web designer must carefully consider:

  • Font family – the appearance of the letters.
  • Font size – how large or small the text appears.
  • Font weight – whether text is normal or bold.
  • Font colour – how clearly text stands out from the background.
  • Text spacing – the spacing between letters and lines.
  • Font compatibility – whether the font displays correctly on different devices and browsers.

For example, an online learning website should use clear, readable fonts so students can comfortably read lesson notes.

SECTION 02

Web-Safe Fonts

2.1 What is a web-safe font?

A web-safe font is a font that is commonly pre-installed on computers and devices, making it likely to display correctly without downloading an additional font file.

The textbook describes web-safe fonts as standard fonts already installed on the user's device.

When a browser displays a web page, it tries to use the font specified by the web designer. If the font is available on the device, the browser can display the text using that font.

2.3 Why do designers use web-safe fonts?

There are several advantages.

1. Compatibility

Web-safe fonts are commonly supported across different operating systems and browsers.

For example, Arial is widely available, so a website using Arial is likely to display consistently across many devices.

2. Faster loading

If the required font is already installed on the user's device, the browser does not need to download an additional font resource.

3. Reliability

Commonly available fonts reduce the chance that the browser will have to substitute an unexpected font.

4. Readability

Many web-safe fonts are familiar to users and suitable for displaying large amounts of text.

5. Easier website maintenance

Developers can use standard fonts without managing separate font files.

2.4 Limitations of web-safe fonts

Web-safe fonts also have disadvantages.

  • There is a limited selection compared with the number of fonts available for download.
  • Websites using only common fonts may have less distinctive typography.
  • Not every font is installed on every operating system or device.
  • Designers have less control over the exact appearance if a requested font is unavailable.

For example, a company may want a distinctive typeface for its brand identity, but that typeface might not be commonly installed.

In this situation, the company may choose to embed a web font.

SECTION 03

Using Web-Safe Fonts in CSS

Web designers can specify fonts using the CSS font-family property.

3.1 Basic example

CSS

body {
    font-family: Arial;
    font-size: 16px;
}

Explanation:

  • body selects the body element of the web page.
  • font-family: Arial; tells the browser to display text using Arial.
  • font-size: 16px; sets the font size to 16 pixels.

3.2 Using fallback fonts

A better approach is to specify several fonts in order of preference.

CSS

body {
    font-family: Arial, Helvetica, sans-serif;
}

The browser follows this order:

1. Try Arial

If available, use Arial.

2. Try Helvetica

If Arial is unavailable, try Helvetica.

3. Use sans-serif

Use an available font from the sans-serif family.

This is called a font fallback list.

It is useful because font availability differs between operating systems and devices.

3.3 Serif, sans-serif and monospace fonts

These categories help designers choose suitable fonts.

Serif fonts

Have small decorative strokes at the ends of letters. Examples include Georgia and Times New Roman. They are often associated with traditional or formal designs.

Sans-serif fonts

Do not have the decorative strokes found in serif fonts. Examples include Arial, Verdana and Tahoma. They are often used for modern website interfaces.

Monospace fonts

Give each character the same horizontal width. Courier New is an example. Monospace fonts are particularly useful for displaying computer code.

These font categories are additional explanations to help students understand how font selection affects web design.

SECTION 04

Embedding Web Fonts

4.1 What is font embedding?

Embedding a web font means making a font available to a website through a font resource so that users can view text in that font even if it is not installed on their devices.

The textbook explains that a web designer can include a resource containing the information required to display a special font.

When a user opens the web page, the browser can download the required font file and use it to display the text.

4.2 How does embedding work?

01Web designer
02Browser requests resources
03Browser displays text

Specifies a custom font in HTML or CSS

Downloads the web page and any required font files

Uses the downloaded custom font when available

4.3 Example from the textbook

The textbook demonstrates the use of the Asap font through Google Fonts.

HTML + CSS

<link
  rel="stylesheet"
  href="https://fonts.googleapis.com/css?family=Asap"
>

<style>
  body {
    font-family: 'Asap';
    font-size: 12px;
  }
</style>

Explanation:

The <link> element connects the web page to a Google Fonts stylesheet.

The stylesheet provides instructions for loading the required font resource.

The CSS font-family property specifies that the body text should use the Asap font.

A more resilient version would include a fallback font:

CSS

body {
    font-family: 'Asap', Arial, sans-serif;
    font-size: 16px;
}

If Asap cannot be loaded, the browser can try Arial or another sans-serif font.

4.4 Using a locally hosted web font

Another method is to store a font file with the website and load it using CSS.

CSS

@font-face {
    font-family: 'SchoolFont';
    src: url('fonts/schoolfont.woff2')
         format('woff2');
}

body {
    font-family: 'SchoolFont', Arial, sans-serif;
}

In this example:

  • @font-face defines a custom font.
  • font-family assigns the name SchoolFont.
  • src identifies where the font file is stored.
  • format('woff2') identifies the font file format.
  • The browser loads the font when it is required for displaying text.

This local-hosting approach is an additional practical example beyond the textbook's Google Fonts demonstration.

SECTION 05

Advantages and Disadvantages of Embedded Web Fonts

Advantages Disadvantages
Designers can choose from a much wider selection of fonts Additional font files can increase loading time
Supports distinctive website branding Font resources may fail to download
Provides greater control over typography External font services usually require an internet connection
Can maintain consistent typography across devices Additional font files require hosting and management

Example:

A company wants its website to use a particular font associated with its brand. The font is not commonly installed on users' devices.

By providing the font as a web resource, the company can make its typography more consistent across devices.

However, if the font file fails to load, the browser should use a suitable fallback font.

SECTION 06

Web-Safe Fonts vs Embedded Web Fonts

Feature Web-safe fonts Embedded web fonts
Availability Commonly pre-installed on devices Supplied through website resources
Font selection More limited Much wider selection
Additional download Usually not required Usually required
Loading performance Generally faster May introduce additional loading time
Design flexibility More limited Greater
Examples Arial, Georgia, Verdana Asap or other custom web fonts

Key distinction: Web-safe fonts rely on fonts commonly available on the user's device, while embedded web fonts allow the website to supply a specific font.

SECTION 07

Selecting Appropriate Fonts for a Website

When choosing typography, designers should consider the website's purpose and target audience.

Example 1: Educational website

A student learning website contains large amounts of text.

A designer might choose Arial or Verdana for lesson content because these fonts are familiar and generally easy to read.

The designer should also use sufficiently large text, consistent heading styles and appropriate line spacing.

Example 2: Business website

A company may use an embedded font to establish a distinctive brand identity.

However, the font must remain readable and should have a suitable fallback.

Example 3: Programming tutorial website

A website teaching programming may use a sans-serif font for explanations and a monospace font such as Courier New for code examples.

This helps students distinguish ordinary text from programming instructions.

SECTION 08

Common Misunderstandings

Misunderstanding 1: Every web-safe font is installed on every device.

In practice, font availability varies. Designers should specify suitable fallback fonts.

Misunderstanding 2: Embedded web fonts must already exist on the user's computer.

Embedded web fonts are supplied through web resources and can be downloaded when needed.

Misunderstanding 3: Embedded fonts always make a website better.

Custom fonts offer more design flexibility, but they may increase loading time and introduce additional dependencies.

Misunderstanding 4: A font that looks attractive is always suitable.

A font must also be readable and appropriate for the intended audience and purpose.
